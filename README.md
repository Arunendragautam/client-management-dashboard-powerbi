# Client Management Dashboard (Power BI + Excel)

## What it does
This project creates deliberately messy sample client and transaction data, cleans it with Python, and prepares Excel sheets for a Power BI dashboard. The Python data pipeline runs locally. A finished `.pbix` dashboard is not included yet; the steps below explain how to build it in Power BI Desktop.

## Files
| File | Purpose |
|---|---|
| `generate_raw_data.py` | Creates `raw_client_data.xlsx` with realistic problems (duplicates, mixed date formats, "N/A", wrong casing, ₹/Rs. in amounts, orphan IDs) |
| `clean_data.py` | Cleans it → `clean_client_data.xlsx` (+ a `DataQualityLog` sheet) |
| `dax_measures.dax` | Calendar table + all KPI measures |

## Run on Windows

Open PowerShell in this folder and run:

```powershell
python -m pip install -r requirements.txt
python generate_raw_data.py
python clean_data.py
```

This creates `raw_client_data.xlsx` and `clean_client_data.xlsx` in this folder. The clean workbook contains `Clients`, `Transactions`, and `DataQualityLog` sheets. The sample data is generated by the script; it is not real customer data.

## Project explanation (Hindi)

- `generate_raw_data.py`: demo clients aur transactions ka Excel banata hai. Isme jaan-boojhkar duplicate rows, alag date formats, missing values aur galat spellings rakhi gayi hain.
- `clean_data.py`: raw workbook ko pandas se saaf karta hai—names, email, phone, city/status aur dates standardize karta hai; duplicate aur invalid transaction rows hataata hai. Saath hi `DataQualityLog` mein har cleaning step ka count deta hai.
- `clean_client_data.xlsx`: Power BI mein import karne ke liye saaf data.
- `dax_measures.dax`: Power BI ke liye calendar table aur KPI formulas—jaise Total Revenue, Total Clients, Active Client %, aur Average Deal Size.
- `raw_client_data.xlsx`: cleaning se pehle ka sample data, taaki aap badlav compare kar saken.

Data flow: **sample data banana → data clean karna → Power BI mein model aur visuals banana**.

## How the cleaning works (and why)
1. **Trim + placeholders → real blanks.** "N/A", "-", "" all become true nulls so they can be counted/handled consistently.
2. **Standardise text.** Names → Title Case, emails → lowercase, cities/status mapped through a dictionary ("pune " → "Pune", "Inactv" → "Inactive").
3. **Phones** → last 10 digits only; anything that isn't 10 digits is blanked rather than guessed.
4. **Dates** parsed with `format="mixed"` so `2024-03-05`, `05/03/2024` and `5 Mar 2024` all work.
5. **Duplicates**: sort by completeness, keep the fullest record per `ClientID`.
6. **Missing values**: categories become `"Unknown"`; amounts are NOT invented — rows with no amount are dropped; contacts stay blank.
7. **Referential integrity**: transactions pointing to a ClientID that doesn't exist are removed.
8. Every step's row count goes to `DataQualityLog` — proof the cleaning is accurate and auditable.

## Build the dashboard in Power BI Desktop (≈30 min)
1. **Get Data → Excel →** `clean_client_data.xlsx`, load `Clients` and `Transactions`. Check column types (dates = Date, Amount = Fixed decimal).
2. **Model view:** create `Clients[ClientID] 1 ──► * Transactions[ClientID]` (single direction). Add `DimDate` (see `dax_measures.dax`), relate `DimDate[Date] 1 ──► * Transactions[TxnDate]`. This star schema is what puts client activity and trends in one view.
3. Paste the measures from `dax_measures.dax`.
4. **Page layout**
   - Top row, KPI **cards**: Total Revenue, Total Clients, Active Client %, Avg Deal Size
   - **Line chart**: DimDate[YearMonth] × Total Revenue (trend)
   - **Clustered bar**: Product × Total Revenue
   - **Donut/column**: Clients[Industry] × Total Clients
   - **Map or bar**: Clients[City] × Total Revenue
   - **Table**: ClientName, City, Status, Total Revenue (sort descending → top clients)
5. **Slicers:** Year, City, Industry, Status. Use **Edit interactions** so slicers filter every visual.
6. Format: consistent theme, titles on every visual, hide helper columns, save as `ClientDashboard.pbix`.

## Resume line this supports
Cleaned raw data (duplicates, inconsistent entries, missing values) → star-schema model → interactive dashboard with KPI cards, charts and slicers.
